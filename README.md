# MARKZ — маркировка и рядовка заполнений витража

**Редакция:** Ред. 36  
**Файл:** [`MARKZ.lsp`](MARKZ.lsp). Грузить оттуда, где лежит: `(load "D:/MarkZ/MARKZ.lsp")`.  
**Репозиторий (справочно):** https://github.com/moleval/MarkZ  

Один модуль AutoLISP: марки заполнений, рядовка обозначений, ведомость.

---

## Установка

```lisp
(load "D:/MarkZ/MARKZ.lsp")
```

В консоли должно появиться:

```text
[MARKZ] Загружен Ред. 36
МАРКА      — полный цикл: сетка или готовые заполнения
МАРКАРОВКА  — марки блоков в «Заполнение в витраж»
МАРКАРЯД    — рядовка из блоков «Ряд заполнений»: номера снизу, буквы справа
МАРКАТАБЛ  — ведомость
МАРКАБЛОК   — Сетка-мультилинии, Точка-мультилинии, Сетка-динамика, Точка-динамика, Полилинии
Точка-динамика — отдельная команда; в списке: 4 или Д
```

## Команды

| Команда | Что делает |
|---------|------------|
| **МАРКАРОВКА** (`MARKZ`) | Марки блоков в «Заполнение в витраж» |
| **МАРКАРЯД** (`MARKAR`) | Рядовка из блоков «Ряд заполнений»: номера снизу, буквы справа |
| **МАРКАТАБЛ** (`MARKTABLE`) | Ведомость: AutoCAD-таблица, XLS, CSV (фолбэк) |
| **МАРКА** (`MARKA`) | Один выбор → все три этапа, **один UNDO** |
| **МАРКАБЛОК** (`MARKFILL`) | Блоки «Заполнение в витраж» по ячейкам; атрибуты пустые |

### МАРКАБЛОК / MARKFILL

```text
МАРКАБЛОК → список [Сетка-мультилинии/Точка-мультилинии/3-Сетка-динамика/4-Точка-динамика/Полилинии]. Точка-динамика также команда, либо `4`, либо `Д`. Буква Т — Точка-мультилинии.
```

| Режим | По умолчанию / Ключи | Как работает |
|-------|----------------------|--------------|
| **Сетка-мультилинии** | **Enter**, `1` | Как раньше: выбор MLINE/LINE/ARC, границы, Т-стыки и все ячейки. Логика не менялась. |
| **Точка-мультилинии** | `2` | Ячейка за ячейкой, пока не Enter. Только мультилинии чертежа, как раньше. |
| **Сетка-динамика** | `3`, команда | Замкнутая ячейка между разными блоками. Блок из линий: только текущая видимость, без отступа 25 мм. Мультилиния без изменений. |
| **Точка-динамика** | команда, `4`, `Д` | Ячейка из соседних блоков каркаса. В списке ключ `4-Точка-динамика`. |
| **Полилинии** | `5` | В конце списка. Готовые замкнутые полилинии границ ячеек |

- **Особенности геометрии и вставки:**
  - Вставка в **левый нижний** угол ячейки (rot 0).
  - Свойства `Ширина в свету` и `Высота в свету` равны точным габаритам светового проёма ячейки.
  - Поддержка **MLINE** (мультилиний) со стойками/ригелями: центральные оси вычисляются через AABB, узлы округляются до 1 мм.
  - **Т-образные примыкания (T-junctions):** если промежуточная стойка подходит снизу к ригелю и не продолжается вверх, ячейки над ригелем автоматически объединяются в единый сквозной проём (например, фрамуга).
  - **Контроль наклона стоек:** строгий допуск `*mark:fill-slope* = 0.0033` (не более 10 мм на 3000 мм высоты) исключает ложные срабатывания.
  - **Очистка атрибутов:** атрибуты нового блока гарантированно обнуляются после установки размеров (чтобы исключить дефолтные значения динамического блока).

### Универсальный запуск — команда МАРКА

Команда **МАРКА** объединяет весь сквозной цикл проектирования:
```text
МАРКА → Режим [Сетка/Заполнения] <Сетка>
```
1. **Режим `Сетка` (по умолчанию / Enter):**
   - **Этап 1: МАРКАБЛОК** — выбор стоек/ригелей, раскладка блоков заполнений в ячейки.
   - **Этап 2: МАРКАРОВКА** — автоматический подхват созданных блоков, выбор «Атрибутов витража», расчёт и запись марок (`А1`, `Б2`...).
   - **Этап 3: МАРКАРЯД** — построение рядовки условных обозначений.
   - **Этап 4: МАРКАТАБЛ** — формирование ведомости заполнений (AutoCAD / Excel / CSV).
   - Весь процесс выполняется в **единой транзакции UNDO** (откат одной командой `_U`).
2. **Режим `Заполнения` (`З`, `F`):**
   - Выполняет этапы 2-4 по уже существующим на чертеже блокам заполнений.

## Формула марки

```text
[Витраж] + БУКВА(по высоте) + НОМЕР(по ширине) + суффикс
```

Буква — вертикальная рядовка (уникальные высоты по возрастанию: 600/1400/2100 → А/Б/В).  
Номер — горизонтальная рядовка (уникальные ширины по возрастанию: 900/1200/1500 → 1/2/3).  
Проверка: 900×2100 → `В1`.

Примеры: `В1`, `Б3стм`, `А2снд`

| Visibility | Суффикс |
|------------|---------|
| Стемалит | `стм` |
| Сэндвич | `снд` |

Алфавит 29 букв, без **Ё**, **Й**, **З**, **О**. Если высот больше, марки продолжаются: `АА`, `АБ`, … `БА`, `ББ`. Одинаковый размер (допуск 0.5 мм) → один базис «буква+номер».

## Рядовка (кратко)

- Индекс `Ряд` = **от размера W/H** (та же логика, что МАРКАРОВКА), не от строки марки.
- Основной ряд — сплошной; наложения — на линиях ниже/правее с шагом **150 мм**, по убыванию длины.
- Dynamic-размер блока: **L/2 + 25** мм.
- Горизонталь (снизу) — номер, поворот **270°**. Вертикаль (справа) — буква, поворот **0°**.
- Перед вставкой старые «Ряд заполнений» в этой зоне удаляются и ставятся заново.
- Группы: `Рядовка горизонтальная`, `Рядовка вертикальная`.

---

## Ведомость (кратко)

- Заголовок **«Заполнение»**
- `№ | Тип | Марка | Высота, мм | Ширина, мм | Кол-во, шт. | Площадь, м2`
- Припуск размеров в таблице: **+26 мм**
- XLS с формулами; CSV только если XLS не создался (в меню CSV нет)

---

## Самодиагностика

При каждой МАРКАРОВКА: **TEST 00–14** + **[DIAG]** по базисам stem/сэнд.

- `TEST 00` — баланс скобок исходника (падает сразу при повреждении файла).
- `TEST 14` — PRE-CHECK; запись только после OK.
- `[DIAG] КОНФЛИКТОВ: N` — у заполнений одного типоразмера разные базисы (сверить W/H в свойствах).

## Конфигурация (важные переменные)

| Переменная | Значение по умолчанию |
|------------|------------------------|
| `*mark:block-fill*` | `Заполнение в витраж` |
| `*mark:attr-mark*` | `Марка` |
| `*mark:prop-width*` / `height` | `Ширина в свету` / `Высота в свету` |
| `*mark:ar-block*` / `ar-attr*` | `Ряд заполнений` / `Ряд` |
| `*mark:ar-offset*` | 1000 |
| `*mark:ar-line*` | 150 |
| `*mtab:allowance*` | 26 |
| `*mark:specials*` | Стемалит→`стм`, Сэндвич→`снд` |

Имена блоков/DP должны **точно** совпадать с чертежом.

```text

├── МАРКАРОВКА (mark:*) — сбор, расчёт, запись «Марка»

```
